# Hi, I’m Antonio

I’m an undergraduate interested in cybersecurity and software development.
I build tools to explore security concepts and make my own workflows easier.

Most of my current work is in Python and Bash. I care about keeping code
modular, understanding how data moves through it, and being able to explain
the decisions behind it.

## Projects

### [Caesar Operator Console](https://github.com/AntoMakh/caesar-operator-console)

A console for running security tools individually or connecting them
through JSON workflows.

I’m building its module system, subprocess execution, option validation,
logging, and workflow engine. The repository includes automated tests
and a local example that discovers web pages and passes them to a
technology-fingerprinting tool.

Recent work includes sharing command construction between execution
paths, separating diagnostic output from workflow results, and fixing
log collisions between runs.

**Python · Bash · subprocess · threading · unittest**

### [Astroyd: Meteor Madness](https://github.com/AntoMakh/astroyd-meteor-madness)
